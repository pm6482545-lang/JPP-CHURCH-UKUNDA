JPP CHURCH WEBSITE - UPLOAD INSTRUCTIONS
1. Upload ALL files in this folder to the same place as your images (jpp.jpg, building.jpg, worship.jpg, praise.jpg, congregation.jpg, fellowship.jpg, mission.jpg ...).
2. index.html is your main page (your index-26.html, upgraded). Rename nothing.
3. Replace https://YOUR-DOMAIN with your real address (e.g. https://www.jpp.co.ke) in every .html file, sitemap.xml and robots.txt.
   Mac/Linux:  sed -i 's#https://YOUR-DOMAIN#https://www.jpp.co.ke#g' *.html sitemap.xml robots.txt
   Or use Find & Replace in any code editor across all files.
4. In Google Search Console: add your site, submit https://YOUR-DOMAIN/sitemap.xml, then use URL Inspection > Request indexing for the home page and each subpage.
5. Create a Google Business Profile for the church and use the main site as its website link.
